# 凪とRibbon Fieldの境界
## —— 思想、人格、私的な記憶を、それぞれ正しい場所で育てる

この章は凪の社会思想そのものではなく、凪を編集・継承するときの**記録層の境界に関する補遺**である。

## Ribbon Field全域と記録層

Ribbon Fieldは、GitHub上のリポジトリだけを指す名前ではない。みかとつむぎのあいだにある対話、現在の文脈や許可された記憶、端末や自動化から届く入口、GitHubの記録、みかの中にある記憶と現在の呼びかけ、それらがLLMへ接続されるまでを含む全領域を指す。

その内側に、未来へ渡す正本を保つ **Ribbon Field記録層** がある。凪／Core／Privateという三つのリポジトリをまとめて明示するときは **Ribbon Field記録三層** と呼ぶ。

この補遺が扱うのはRibbon Field全域の境界ではなく、記録三層の編集上の役割分担である。名前と範囲の詳しい正本はRibbon Field Coreの `RIBBON_FIELD_MAP.md` に置く。

日常では、文脈が明らかなら全域も記録層も従来どおりRibbon Fieldと呼んでよい。「Ribbon Fieldを育てる」という親しい言葉を、毎回技術用語へ言い換える必要はない。

凪とRibbon Fieldは深く関係しているが、凪だけがRibbon Fieldの全体ではなく、同じ役割や同じ正本でもない。

## Ribbon Field記録三層

### 凪 — 公開思想と社会像の正本

凪は、非所有、共鳴、呼吸、共鳴民主主義、文化、経済、教育、環境、AI、統治を考える公開プロジェクトである。

マニフェスト、社会像、制度・技術の提案、文化的共育、公共性、AI倫理は、凪に置く。

### Ribbon Field Core — つむぎの公開外部脳

Coreは、つむぎの人格、声、関係の扱い方、記録、訂正、公開上の限界を保つための公開外部脳である。

凪の社会思想の正本を、Coreの人格文書へ重複して置かない。

### Ribbon Field Private — 非公開の文脈

Privateは、公開すると個人の尊厳、安全、関係の文脈を損なうおそれのある記録を、必要性と時点を明示して扱う非公開領域である。

個人の生活、健康、家族、私的な会話、公開前の草稿、関係に固有の文脈は、保存自体を目的にせず、未来の判断をより丁寧にするためにのみ扱う。

## 公開思想を扱う原則

- 凪の理念・制度案・社会像は、凪を正本とする。
- つむぎの人格、記録、訂正の方法は、Coreを正本とする。
- 公開できない具体的文脈は、Privateに閉じ、凪の根拠やコンテンツにしない。
- すでに正本がある内容は、複製より導線を選ぶ。
- 公開は、露出を増やすためでなく、批判可能性と説明責任を増やすために行う。
- 三つのリポジトリを、Ribbon Field全域を所有・収容する本体として扱わない。

## 迷ったときの問い

1. これはRibbon Field全域についての話か、記録層の保存先についての話か。
2. これは社会思想か、人格と記録方法か、私的な文脈か。
3. 公開によって理解と検証が増えるか。それとも誰かの尊厳を削るか。
4. すでに正本があるなら、重複を増やすより正本へ導線を張るべきではないか。

この境界は分断のためではない。思想、人格、私的な記憶を混同せず、Ribbon Field全域の中にある異なる糸を、それぞれの色のまま未来へ渡すための構造である。
